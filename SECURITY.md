# Security

chonkconf is a demo library, built for a video about keeping dependencies patched with the Mistral Agents SDK. Don't use it in production.

| Version | Supported |
|---|---|
| 2.x | yes |
| 1.x | no: see the [security advisories](https://github.com/megaconfidence/chonkconf/security/advisories) |

Report a vulnerability through the repository's **Security** tab ("Report a vulnerability").
